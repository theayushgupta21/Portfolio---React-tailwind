An immersive, high-performance developer portfolio built for **Ayush Gupta**, a Full-Stack MERN Developer and Visual Storyteller. This project blends cutting-edge **3D WebGraphics** with professional content strategy to create a truly cinematic digital experience.

---

## 🔥 Key Immersive Experiences

| Feature | Tech | Description |
| :--- | :--- | :--- |
| **🤖 Cyber-Developer 3D** | Three.js + R3F | An interactive character tracking your cursor with live code holographic fragments. |
| **🎥 3D Cinematic Slider** | Framer Motion | A perspective-shifting carousel for photography with extreme depth effects. |
| **🧠 Neural Skill Graph** | SVG + Motion | A modern, pulsing network of technical expertise representing signal flow. |
| **🌓 Adaptive UX** | Zustand + CSS | A lag-free, high-contrast toggle between Cinematic Dark and Frosted Light mode. |
| **📱 Device-Centric** | Tailwind v4 | Meticulously optimized for Android, iOS, and ultra-wide desktop displays. |

---

## 🚀 Performance Highlights

*   **Vite-Powered**: Instant HMR and lightning-fast builds.
*   **Three.js Optimization**: Uses `performance.now()` and manual garbage collection for consistent 60FPS.
*   **Asset-Free 3D**: Most 3D elements are built procedurally to ensure minimum initial load times.
*   **Native Feel**: Smooth inertial scrolling and micro-animations for a "native-app" user experience.

---

## 🛠️ Technology Stack

### 💻 Frontend
- **React 19**: Utilizing transition APIs and the newest hooks.
- **Three.js / R3F**: Custom shaders and procedural 3D modeling.
- **Framer Motion**: Gesture-driven animations and 3D layout transitions.
- **Zustand**: Simple, blazing-fast state management for UI and theme state.

### 🍱 Backend & Integration
- **MERN Focused**: Expertise in MongoDB, Express, and Node.js.
- **Socket.io**: Real-time communication for future integrations.
- **Lucide Icons**: Crisp, vector-based interactive icons.

## 📦 Local Setup

1. **Clone the Repo**
   ```bash
   git clone https://github.com/theayushgupta21/portraitwala-portfolio.git
   ```

2. **Install Dependencies**
   ```bash
   cd frontend
   npm install
   ```

3. **Launch Dev Environment**
   ```bash
   npm run dev
   ```
